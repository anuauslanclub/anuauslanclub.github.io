# Auslan Classes through the ANU Auslan Club

We are pleased to announce that enrolments are now open for Semester 2, 2026 classes! To enrol, you will need to [book in your preferred day](https://outlook.office.com/book/ANUAuslanClub1@ANU365.onmicrosoft.com/?ismsaljsauthenabled) and upon successful booking, pay for the classes through [Rubric](https://campus.hellorubric.com/?tab=memberships&s=6331). Please find more detailed instructions [below](#enrolment-process).

Spots are limited and classes start next week, so make sure to get in quick!

## Class Details

Classes start next week (Week 4) and will run with one session per week for six weeks (Weeks 4-9 inclusive). They will not run over the mid-semester break. Students will have the option to enrol in the class running on Wednesdays or Fridays. 

Classes will be online, so please ensure that you have a personal device (laptop or tablet) with a working webcam.

Each class will be 1 hour of content (9.30am-10.30am), followed by an optional 30 mins to allow for student questions and clarification.

## Enrolment Process

To enrol in your preferred class, [go to our bookings page](https://outlook.office.com/book/ANUAuslanClub1@ANU365.onmicrosoft.com/?ismsaljsauthenabled) and select the start date of your preferred class (i.e. select 19 August for Wednesday classes or 21 August for Friday classes). You only need to select the start date — all the subsequent weeks are included in this booking. This will reserve a spot for you in the class.

Once you have received your booking confirmation, please proceed to [Rubric](https://campus.hellorubric.com/?tab=memberships&s=6331) and pay for the classes by signing up for our membership called *Auslan Classes - Semester 2, 2026*. The cost will be $50.

Once you have submitted a booking and provided payment, you are officially enrolled in the class!

We will email you with instructions about how to join the class online before your class start date.

Please feel free to email us at auslan.club@anu.edu.au with any questions.
